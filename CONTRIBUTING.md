# Contributing to sachncs/sachncs

Thanks for taking the time to improve this profile repository. Contributions
are welcome — typo fixes, link corrections, and wording suggestions are
especially appreciated.

## What this repository is

This is the source for the GitHub profile README at `github.com/sachncs` and
the GitHub Pages site at `https://sachncs.github.io/sachncs/`. It is **not**
a code project — it is documentation and identity. Almost every change is a
copy edit, link fix, or asset update.

## What is in scope

- Typo, grammar, and wording fixes in `README.md`.
- Link fixes in the "Selected Work" table or anywhere else.
- New entries for "Selected Work" only if the project is public and reachable
  on this GitHub account.
- Accessibility improvements (alt text, semantic structure).
- CI / lint / link-checker improvements under `.github/workflows/`.
- Brand asset improvements (favicon, monogram, CSS) when they preserve
  visual identity.

## What is out of scope

- Substantial rewrites of positioning without prior discussion (open an
  issue first).
- Adding new sections or features that have not been requested via an issue.
- Bulk automated edits.

## How to contribute

1. Open an issue describing the change. Use the **Typo / content fix** or
   **Feature request** template under `.github/ISSUE_TEMPLATE/`.
2. Fork the repository and create a topic branch.
3. Make the change in the smallest possible diff.
4. Run `markdownlint-cli2 README.md` locally if you have it; CI will run it
   on your PR.
5. Open a pull request using `.github/PULL_REQUEST_TEMPLATE.md`.
6. Expect a response within 2–3 working days.

## House style

- One sentence per line where possible in `README.md` — easier to review.
- Prefer concrete, quantified language over adjectives.
- Keep total README length under ~120 lines.
- Avoid emojis outside the contact block.
- Do not edit `LICENSE`, `CODE_OF_CONDUCT.md`, or `SECURITY.md` without an
  issue discussion.

## Reporting issues not appropriate for a public PR

Security vulnerabilities: see `SECURITY.md`.
Code of conduct violations: see `CODE_OF_CONDUCT.md`.
